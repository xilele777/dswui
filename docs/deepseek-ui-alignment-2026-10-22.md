## 验证

- `npx tsc --noEmit`、`npm run build` 通过；单文件产物为 `dist/index.html`。
- 桌面 1482×780：搜索图形 x=198.2、折叠图形 x=232.2，与原站实测一致；首页输入卡 y=325.7、宽 776、高 123.6，与原站实测一致。
- 标题编辑框短文字宽 57px，长文字限制为 480px。
- 多选取消删除后保留选择；折叠后主区左边界归零，工具组仍可展开侧栏。
- 悬浮目录展开后条目留在容器内；390px 移动端未出现页面横向溢出。
- 浅色、深色和移动端截图位于 `docs/local-probe/aligned-*.png`。使用隔离浏览器中的本地演示数据检查，未对真实会话执行删除。

本记录的精确尺寸对应本次视口和发布版本，不表示所有页面状态均已逐像素比较。

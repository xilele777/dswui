Request ​ application/json Body required query string required Possible values: non-empty and <= 128 characters The search query. Supports operators such as site: , -site: , and quoted phrases. Must contain 1 to 128 Unicode characters and cannot be all whitespace. count integer Possible values: >= 1 and <= 50 Default value: 10 The number of results to return, between 1 and 50. Defaults to 10. ori_question string nullable Possible values: non-empty and <= 128 characters The user's original question that triggered the search, between 1 and 128 characters. Providing it can improve query understanding. null is treated as not provided. localization string An optional IP address used to localize search results. Defaults to an empty string. need_content boolean Whether to return page content in content . Defaults to false ; when false , content is always an empty string. Responses ​ 200 OK, returns the search results. application/json Schema Example (from schema) Example Schema results object[] required The search results. Empty when the query matches no results.

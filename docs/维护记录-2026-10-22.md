# 2026-10-22 体验优化记录

## 背景

现有客户端已经具备对话、流式输出、服务商设置和本地历史，但高频入口与 chat.deepseek.com 的使用习惯仍有差异。本次先处理搜索、新对话、设置三个用户最容易感知的区域。

## 已完成

### 搜索对话

- 顶栏新增搜索按钮，侧栏收起时也可以直接打开搜索。
- 支持 `Ctrl/Cmd+K` 打开搜索层并自动聚焦。
- 有搜索词时提供清空按钮；无匹配结果显示明确状态。
- 搜索仍覆盖会话标题和消息正文，保持本地检索，不引入额外后端。

### 新对话

- 顶栏按钮从单独图标调整为“加号 + 新对话”文字入口，保留 `Ctrl/Cmd+K` 快捷键。
- 侧栏按钮保持原位置，桌面端和移动端都可用。

### 设置

- 弹窗增加副标题和“服务商”“连接参数”“外观与生成”分组标题。
- 增加设置弹窗的 `aria-labelledby` 与关闭按钮标签，改善键盘和读屏使用。

## 验证

- 运行 `npm run build`，确认 TypeScript、Vite 构建和单文件内联流程均通过。
- 检查搜索入口、折叠侧栏、无结果状态和设置分组的窄屏布局。

## 后续积累

- 继续对齐会话行的更多操作菜单和移动端顶栏密度。
- 评估搜索结果是否需要按消息片段高亮；当前先保持原版的标题、摘要和时间三列信息。
- 若新增官网观察，追加到现有主题文档并在本目录登记日期记录。

## 二次逆向取证补记

本次通过原版 `chat.deepseek.com` 首屏、搜索层、账户菜单、系统设置和已有对话页进行可见界面取证，确认以下结构差异：

- 首页主区没有模型选择顶栏，中心标题为“你好，有什么我能帮你的吗？”，输入卡宽约 776px。
- 侧栏顶部是品牌、搜索图标和收起图标；搜索不常驻侧栏，而是打开带背景模糊的居中搜索层，输入提示为“搜索对话内容...”。
- “开启新对话”是白底胶囊按钮，旁边显示 `Ctrl + J`，而不是纯蓝色按钮。
- 已有会话页顶栏只显示会话标题和分享入口；模型与服务商不占用主顶栏。
- 左下角账户菜单包含下载手机应用、系统设置、数据管理、帮助与反馈；系统设置采用左侧导航布局。
- 输入卡的深度思考、智能搜索位于左下，附件图标位于右下发送按钮左侧。

本轮实现已落地：搜索层、`Ctrl/Cmd+J` 新对话、`Ctrl/Cmd+K` 搜索、会话标题顶栏、账户菜单、设置左侧导航、输入卡附件位置和首页垂直间距。

## 第五轮：系统设置弹窗按官方重做

官方设置容器（`main.js` 中账号菜单分支）结构为：

```
<标题「系统设置」>
<div class="_iW">
  <nav items=[通用设置 general, 账号管理 account, 数据管理 data, 服务协议 policy] />
  <scroll-area className="Qs" stretchContent>
    <pane className="YE">{general | account | data | policy}</pane>
  </scroll-area>
</div>
```

尺寸与间距（`main.pretty.css`）：

- `.ds-modal-content._6c040bb`：760×500，圆角 24
- header：`padding:22px 24px 0`，标题 16/24，`margin-bottom:12px`
- nav `d316d158`：宽 172、gap 4、`padding-top:4`；项 `min-height:40`、`width:calc(100% - 8px)`、`margin:0 4px`、`padding:9px 10px 9px 8px`、`radius:12`，**选中只换灰底**
- 滚动区 `_574eb80`：`margin-right:-24px` 让滚动条贴弹窗右边；内容 `_2db4123`：`padding:0 24px`
- 主题选择器 `b0db7355`：1px 描边胶囊 + 1px padding + 4px gap，选中项白底 + `0 4px 8px rgba(0,0,0,.04)`

本项目落地：

- 通用设置：主题（浅色 / 深色 / 跟随系统，分段胶囊）、发送方式、显示 token 用量
- 服务商与密钥：服务商选择行 + 连接参数表单（Base URL / Key / 模型 / Temperature / Max tokens / 系统提示词）
- 数据管理：导出 / 复制配置 / 载入演示 / 删除所有对话，均为 60px 行 + 右侧按钮
